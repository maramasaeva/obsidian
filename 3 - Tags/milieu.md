# milieu

the conditioning ground a technics grows out of — geographical, climatic, social, metaphysical. in hui (via leroi-gourhan and watsuji's *fūdo*, wind + soil) the milieu is what turns a universal technical *tendency* into a cosmologically specific technical *fact*. not destiny — watsuji notes the fūdo *is not eternal* — but the soil the cosmology takes root in.

- [[Technical tendency vs technical fact — the same calendar is not the same time]] — the milieu is what makes the same object mean differently.
